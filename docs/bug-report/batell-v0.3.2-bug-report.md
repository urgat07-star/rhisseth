# Багрепорт опубликованной версии batell v0.3.2

Дата фиксации: 25.09.2026. Источник: проверка пользователя после публикации. Версия исправления: `batell v0.3.3`.

## 1. Генерал не перемещается после завершения своего хода

**Наблюдение:** пользователь не может выбрать новое положение генерала.

**Причина:** после нажатия «Конец хода» сервер корректно запрещает игровые действия до следующего глобального хода, однако интерфейс молча игнорировал выбор генерала и не объяснял блокировку.

**Исправление:** при выборе генерала после завершения хода интерфейс сообщает, что ход уже отдан и нужно дождаться игроков либо использовать «Пропустить ход» после её активации.

## 2. Кнопка «Пропустить ход» не активируется через две минуты

**Наблюдение:** после завершения хода кнопка остаётся недоступной.

**Причина:** срок ожидания кнопки составлял две минуты, но игрок считался онлайн пять минут после последнего обращения. Из-за несогласованных интервалов недавно отключившийся соперник ещё три минуты блокировал пропуск.

**Исправление:** окно присутствия сокращено до 90 секунд. Активная страница обновляет присутствие каждые 30 секунд, поэтому открытый клиент остаётся онлайн; закрытый клиент перестаёт блокировать пропуск до истечения двухминутного ожидания. Интерфейс также показывает серверный текст ошибки вместо общего HTTP-кода.

## 3. Не видно, чей ход ожидается

**Запрос:** показывать имя каждого пользователя, который ещё не завершил текущий глобальный ход, и разрешать пропуск хода конкретного офлайн-игрока кнопкой «Пропустить ход».

**Исправление:** API часов возвращает список ожидаемых игроков, их состояние присутствия и доступность пропуска. Панель показывает `Ожидаем: имя`, а доступная кнопка получает подпись `Пропустить ход: имя`. Сервер принимает идентификатор конкретного игрока, проверяет, что он ещё не завершил ход, находится офлайн и истекли две минуты, после чего засчитывает пропуск только ему. При нескольких ожидающих игроках они пропускаются последовательно.

Рядом с кнопкой отображается обратный отсчёт `До пропуска: ММ:СС`. После истечения ожидания надпись меняется на `Можно пропустить ход`.

## Проверка

Проверить завершение хода, блокировку движения с объяснением, имена всех ожидаемых игроков, активацию адресного пропуска через две минуты при офлайн-сопернике, запрет пропуска при активном сопернике, последовательный пропуск нескольких офлайн-игроков и начало нового глобального хода после последнего голоса или пропуска.
