# Багрепорт опубликованной версии batell v0.3.4

Дата фиксации: 25.09.2026. Источник: сообщение пользователя после тестирования опубликованной версии `batell v0.3.4`. Статус: **зафиксировано, требует исправления**. Планируемая версия исправлений: `batell v0.3.5`.

## 1. На тактической карте нет разметки гексов и отсутствует подходящий фон

**Наблюдение:** на боевой карте не видна полноценная разметка гексагональной сетки. Текущий фон недостаточно различим и не соответствует задаче тактического поля.

**Ожидается:** все клетки тактической карты имеют видимые границы, гексы стыкуются без зазоров и однозначно различаются при выборе, перемещении и атаке. Базовый временный фон должен быть зелёным.

**Расширение:** подготовить каталог тактических фонов. Для каждого фона нужны идентификатор, путь к файлу, признак доступности и, при необходимости, условия выбора. Карта должна поддерживать случайный выбор фона или выбор по типу/координатам гекса, на котором начался бой. Конкретный формат каталога и админский интерфейс требуют отдельного согласования; до этого нужен рабочий зелёный fallback.

**Проверить:** сетку 8×8, стыки соседних гексов, масштабирование окна, видимость координатных границ, зелёный фон при отсутствии записи каталога и сохранение выбранного фона при обновлении боя.

## 2. После боя нельзя выбрать второго генерала

**Наблюдение:** после завершения боя первый генерал возвращается на карту, но выбрать другого доступного генерала и продолжить его действия нельзя.

**Ожидается:** после закрытия результата боя карта обновляется без перезагрузки, список активных генералов синхронизируется с сервером, любой генерал с оставшейся логистикой может быть выбран, его доступные гексы подсвечиваются, а перемещение открывает меню действий.

**Проверить:** победу, поражение и отступление; наличие одного и нескольких генералов; удаление погибших/пленных генералов из списка; выбор второго генерала после боя; сохранение позиции и оставшейся логистики первого генерала.

## 3. После окончания и пропуска всех игроков не начинается новый раунд

**Наблюдение:** после нажатия «Конец хода» и пропуска пользователей интерфейс не показывает надёжное начало нового раунда. Логистика генералов не сбрасывается, и повторное движение не становится доступным.

**Ожидается:** после голосов всех участников и адресного пропуска всех недоступных игроков сервер атомарно увеличивает номер глобального хода. Клиенты получают новое состояние раунда, для каждого активного генерала восстанавливается полный запас логистики, сбрасываются флаги действий, а выбор и движение снова доступны. На карте явно показываются новый номер хода и список генералов с состоянием `0/N ходили`.

**Проверить:** переход после обычных голосов, после одного пропуска и после нескольких последовательных пропусков; одновременное обновление двух браузеров; сброс логистики только при переходе на новый глобальный ход; отсутствие повторного сброса при обновлении страницы; доступность второго генерала после перехода.

## Ограничения фиксации

Этот документ основан на сообщении пользователя; новая браузерная сессия и серверная трассировка для v0.3.4 ещё не выполнены. Каталог фоновых изображений пока является требованием к проектированию, а не существующим серверным контрактом. Исправления и публикация `v0.3.5` не утверждаются этим документом.
