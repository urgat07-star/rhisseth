# Отчёт об ошибке Rhisseth Fix 0.4.3

- Дата обнаружения: 02.10.2026
- Затронутая версия: Fix 0.4.3
- Версия исправления: планируется Fix 0.4.4
- Статус: воспроизведено по серверной логике, исправлено локально, не опубликовано

## Проявление

После начала тактического боя часть бойцов нападающего могла двигаться, а бойцы с меньшей инициативой оставались недоступными. Завершение раунда повторяло ситуацию. Некоторые заблокированные бойцы получали ход только после уничтожения противника.

## Причина

Очередь инициативы считала переместившегося бойца без завершённой атаки всё ещё активным независимо от наличия доступной цели. Такой боец с высокой инициативой оставался первым в очереди и не пропускал союзников с меньшей инициативой. После уничтожения цели состав доступных действий менялся, из-за чего блокировка могла исчезнуть.

## Исправление

Переместившийся боец сохраняет активацию только при наличии живой цели в дальности разрешённой атаки. Если атаковать некого, его действие завершается и очередь переходит дальше. Правило выстрела мобильного стрелка после неполного движения сохранено.
