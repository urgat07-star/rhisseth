# Багрепорт опубликованной версии batell v0.3.3

Дата фиксации: 25.09.2026. Источник: повторная игровая проверка пользователя после публикации. Версия исправления: `batell v0.3.4`.

## Генерал подсвечивает путь, но не перемещается

**Наблюдение:** генерал выбирается, соседние доступные гексы подсвечиваются, но клик по ним не меняет позицию и не открывает действия «Захватить», «Ограбить», «Ничего не делать».

**Причина:** API карты возвращает координаты `Q` и `R` строками. Клиент отправлял эти значения в JSON перемещения без преобразования, а серверный контракт принимает только целые числа. Запрос отклонялся с HTTP 400 до выполнения перемещения. Подсветка работала, потому что её расчёт независимо преобразовывал координаты через `Number`.

**Исправление:** перед отправкой POST перемещения клиент явно преобразует обе координаты в числа. Добавлена автоматическая проверка клиентского контракта.

**Проверить:** перемещение на соседний гекс каждого типа владения, расход логистики, открытие меню действий после успешного перехода, сообщение сервера при действительно запрещённом переходе.
