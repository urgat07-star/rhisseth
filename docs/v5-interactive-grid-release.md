# V5: единая интерактивная сетка на всю карту

Ранее видимая сетка была частью PNG, а области выбора строились отдельно
по старой геометрии. При наведении и открытии редактора границы расходились.

Теперь используется чистая подложка `terrain-map-group3-artistic-v5-no-grid.png`.
SVG-полигоны одновременно показывают сетку и обрабатывают выбор, поэтому
видимые границы совпадают с интерактивными. Изображение сохраняет пропорции
1508×1043; SVG масштабируется вместе с ним.

Сетка покрывает всю подложку, включая частично видимые гексы по краям.
Категория «Вне полотна» из прежнего импорта больше не скрывает клетки,
которые геометрически попадают на изображение. Координаты существующих
гексов и их сохранённые характеристики не меняются автоматически.

Для отсутствующего гекса открывается карточка с пустыми параметрами.
При первом сохранении admin/moderator создаёт запись в PostgreSQL;
повторное сохранение объединяет переданные поля с существующими данными.
Проверки ролей, CSRF, полей и числовых диапазонов сохраняются.
Вставки за пределами сетки полотна запрещены.

Проверено восемью локальными тестами, включая покрытие 70 400 точек,
сохранение отсутствующего гекса внизу слева, отказ вставки вне полотна
и ограничения доступа. Проверка опубликованной версии сверяет HTML,
PNG, JS/CSS и покрытие сетки через авторизованный запрос к домену.

При публикации создаётся резервная копия БД и проверяется неизменность
числа и контрольной суммы гексов. Для обновления API требуется перезапуск
приложения. Полный перезапуск сервера не нужен.

Параметры местности, ресурсов и рейтинги не выводятся автоматически
из новой иллюстрации: их актуализация остаётся отдельной задачей.
