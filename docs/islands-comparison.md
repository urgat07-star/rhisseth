# Сравнение островов основной карты

Страница: https://rhisseth.ru/map/.
Основная карта: https://rhisseth.ru/interactive-map/.

16.09.2026 опубликован новый программный вариант islands-v2, подготовленный
из оригинальной Artistic V5. После уточнения владельца применяется простое
правило: минимально сдвигать небольшие острова, через которые проходят границы
гексов. Нейроперерисовка и заданные ранее ручные переносы Q/R в этом варианте
не применяются. Крупные острова и уже помещающиеся островки сохраняют положение.

21 остров смещён на 2–24 пикселя исходного полотна 1508×1043.
10 островков уже находятся внутри гексов и оставлены на месте.
Острова, чьи контуры не помещаются в один гекс, сохраняются.
Сетка соответствует основной карте: радиус 80, SVG 3200×2200.
За береговой маской сохранён зазор минимум 1,5 пикселя до линии сетки.

Рисунок островов переносится целыми пикселями без масштабирования и поворота.
На прежних местах локально восстанавливается море; окружающая вода по краям
перенесённых фрагментов плавно смешивается. Пиксели самих островов, остальной
суши и изображения за пределами областей правки проверены на точное совпадение
с оригиналом. Всего изменено 54797 пикселей, примерно 3,5% изображения.

## Локальная подготовка

Генератор: scripts/automation/Prepare-IslandsPreview.py.
Шаблон просмотра: scripts/templates/islands-preview.html.
Окружение: .local/island-editor/; зависимости: Pillow, numpy,
opencv-python-headless. Запуск из корня проекта:

```powershell
& .local/island-editor/Scripts/python.exe scripts/automation/Prepare-IslandsPreview.py
```

Результат: reports/previews/islands-v2/terrain-map-islands-preview-v2.png.
Просмотр до/после: reports/previews/islands-v2/index.html.
Перечень сдвигов, SHA256 и результаты проверок:
reports/previews/islands-v2/placement-analysis.json.

В просмотре доступны переключение оригинала и нового варианта, сетка,
подписи Q/R и стрелки смещений. Редактор игровых данных отсутствует.

## Публикация и проверки

Первоначальная публикация /map/: scripts/automation/Publish-IslandsFromDocker.py
и scripts/automation/Publish-IslandsPreviewVps.py.
Обновление islands-v2: scripts/automation/Update-IslandsFromDocker.py
и scripts/automation/Update-IslandsPreviewVps.py.
SSH использует закреплённые host keys, Python VDS —
/opt/rhisseth/venv/bin/python. Проверенные SHA256 исходной и результирующей карт
сверяются перед обновлением. HTML заменяется атомарно после доставки PNG.

Файлы VDS: /opt/rhisseth/previews/map/.
Доступ требует входа для HTML и PNG, индексация и кэширование отключены.
Проверено получение /map/ и обоих PNG после входа по точным SHA256;
без входа показывается страница входа. Основной frontend, данные hexes
и текущий nginx конфиг не изменены. Временный проверочный аккаунт и сессии
удалены. TLS проверен с обычным CA trust. Приложение и nginx не перезапускались.

Снимок предыдущей страницы:
 /opt/rhisseth/backups/20260916-201240-map-before-v2/.
Журнал VDS:
 /opt/rhisseth/reports/automation-logs/2026-09-16/20260916-201240-islands-map-v2-update.md.
Локальный журнал:
 reports/automation-logs/2026-09-16/20260916-201218-islands-v2-local-docker.md.

Для возврата прежнего просмотра восстановить только index.html из снимка.
Старый PNG сохранён на VDS. Основная интерактивная карта не заменялась.

Для удаления маршрута убрать только location = /map,
location = /_islands_map_identity и location ^~ /map/ из текущего nginx
virtual host, проверить nginx -t и выполнить reload. Не восстанавливать
весь старый конфиг поверх последующих изменений.
