# batell v0.3.3

Дата публикации в GitHub: 25.09.2026. Ветка `batell`, коммит
`f1417c2` с сообщением `Fix turn ownership and targeted skip in batell v0.3.3`,
аннотированный тег `v0.3.3` опубликованы.

Исправления по [багрепорту v0.3.2](../bug-report/batell-v0.3.2-bug-report.md):

- окно присутствия игрока согласовано с двухминутным ожиданием ручного пропуска хода;
- активный браузер поддерживает присутствие регулярным запросом, отключившийся игрок перестаёт блокировать кнопку заранее;
- попытка выбрать генерала после голосования показывает причину блокировки;
- ошибки пропуска показывают сообщение сервера.
- панель показывает имена пользователей, чей ход ещё ожидается;
- кнопка пропуска указывает имя офлайн-игрока и засчитывает пропуск именно ему; несколько игроков обрабатываются последовательно.
- рядом с кнопкой отображается посекундный обратный отсчёт до разрешённого пропуска.

Миграция базы данных не требуется.
