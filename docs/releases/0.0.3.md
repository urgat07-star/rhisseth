# Rhisseth 0.0.3

Дата: 22.09.2026.

## Единая навигация интерфейса

- Личный кабинет открывается в модальном окне поверх интерактивной карты.
- Профиль больше не открывается в новой вкладке.
- Создание баронии открывается в том же модальном окне.
- Регистрация открывается модально со страницы входа.
- Добавлены закрытие окна по кнопке, клавише `Esc` и клику по затемнённому фону.

Серверные API, авторизация, данные пользователей и игровая логика не изменялись.
