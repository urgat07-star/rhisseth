# Rhisseth 0.0.2

Дата: 18.09.2026.

- Художественная карта Artistic V6, таблица гексов и расширенные параметры территорий.
- Создание баронии из свободных соседних гексов, выбор герба и цвета.
- Отдельный кабинет игрока: сведения о землях, ресурсы, настройки аккаунта,
  переименование баронии и подтверждённый отказ от владения.
- Панель управления пользователями, ролями и удалением аккаунтов с аудитом.
- Скрипты резервного копирования и восстановления, проверка архивов и миграций,
  контейнер восстановления и документация для администратора и дизайнера.
- Управление SSH/SFTP-доступом игровых администраторов через серверную проверку роли.

## Совместимость

Новые миграции: `003_hex_metadata.sql` — `008_player_barony_rename.sql`.
Перед обновлением требуется резервная копия PostgreSQL; миграции выполняются
по порядку. Публикация релиза в GitHub сама по себе не выполняет развёртывание.

Население, армии, торговля, налоги и дипломатические действия пока не реализованы.
Секреты, локальные отчёты и конфиденциальные архивы передачи в релиз не входят.
