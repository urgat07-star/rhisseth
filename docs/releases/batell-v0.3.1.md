# batell v0.3.1

Исправления по [баг-листу](../bug-report/batell-v0.3.0-bug-report.md) от 24.09.2026.

Дата публикации в GitHub: 25.09.2026. Ветка `batell`, коммит
`f2ca399efb8acd135e2f22c2fb0dfd5bd6604d79` с сообщением
`Fix batell v0.3.0 bugs for v0.3.1`, аннотированный тег `v0.3.1` опубликованы.

- Исправление оформления даты исключено из релиза по уточнению пользователя: дизайнер выполнит его вручную.
- Поле боя отображает гексы, фигуры юнитов, активных бойцов, достижимые клетки и доступные цели. Правая кнопка открывает характеристики.
- После боя карта обновляется без перезагрузки страницы. Ошибки API показываются отдельно от ошибки загрузки карты.
- После голоса «Конец хода» сервер разрешает ручной пропуск через две минуты, если непроголосовавший соперник офлайн. Таймер не переключает ход автоматически; действие записывается в аудит.
- Верхний боевой журнал на русском показывает атакующего, цель, броски атаки и защиты и нанесённый урон.
- В админке пояснено, как вводить несколько рек отдельными цепочками связей.
- Уровень юнита 1–5 доступен в каталоге и форме администрирования.
- Генерал может перемещаться с гекса любого владельца на любой доступный соседний сухопутный гекс. «Ничего не делать» выполняет переход и списывает логистику.
- Захват требует соседства цели с территорией баронства, а не владения исходным гексом. Условие проверяется при начале и завершении боя.

Проверка перед публикацией: 77 серверных тестов прошли, один пропущен;
синтаксис JavaScript и `git diff --check` проверены.
