## Запрос

Перенести в репозиторий изменения, выполненные администратором на VDS в редакторе «База военных юнитов»: броню, защиту, атаку, дальность, скорость, инициативу, отображаемые и структурированные цены, доступность и цепочки улучшений.

## Выполнение

Файловый `Sync-FromVds` не содержит состояние PostgreSQL, поэтому справочник был отдельно экспортирован read-only из `unit_catalog`, `unit_resource_costs` и `unit_upgrade_requirements`. Получен и разобран JSON для 21 юнита без пользователей, секретов и иных игровых данных.

Миграция `044_vds_unit_catalog_sync.sql` фиксирует состояние VDS как воспроизводимую базу знаний. Она обновляет параметры существующих ID 1–21, полностью синхронизирует их структурированную стоимость и семь связей улучшения.

## Совместимость и изменения БД

Добавлена новая миграция. Таблицы и типы не меняются. При будущем применении значения каталога будут приведены к экспортированному состоянию; существующие армии сохраняются, поскольку ID юнитов не меняются.
