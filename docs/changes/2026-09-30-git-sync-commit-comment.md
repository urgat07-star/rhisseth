## Запрос и изменение

Оператор потребовал сохранять в отчёте Git-sync тот комментарий, который он вводит при создании коммита. Пункты 3 и 5 интерактивного меню теперь обязательно запрашивают комментарий и передают его соответственно в `Publish-ToGitHub.ps1` и `Sync-FromVds.ps1`. Стандартная автоматически подставленная тема для импорта VDS удалена.

Каждый отчёт `reports/Git-sync/*.md` записывает полный SHA в поле `Git commit` и точную тему HEAD отдельным полем `Комментарий коммита`. Правило зафиксировано в `AGENTS.md`, полном руководстве и краткой последовательности.
