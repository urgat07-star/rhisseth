# Изменение: интерфейс найма генералов и юнитов

- Дата: 30.09.2026
- Планируемая версия: Fix 0.4.0.7
- Ветка: текущая рабочая ветка; отдельная `fix/*` не создавалась
- Commit/tag: ещё не созданы
- Статус: опубликовано напрямую на VDS; VDS временно опережает Git

## Причина

Старый интерфейс не объяснял, почему найм генерала или юнита не состоялся. Выбор юнита выполнялся через обычный список без изображений, а дефицит золота, ресурсов, места или требуемого предыдущего юнита становился известен только после запроса.

## Изменение поведения

- Нанятые генералы показаны в верхней части раздела армии карточками с изображениями.
- Нажатие на генерала открывает модальное окно состава армии.
- Для бойцов показаны изображение, текущие и максимальные жизни, атака, защита, дальность и скорость.
- Под армиями добавлен каталог найма генералов с изображениями, характеристиками и ценой.
- Найм юнитов вынесен в отдельное модальное окно с карточками, параметрами и ценой.
- Клиент заранее рассчитывает дефицит золота и каждого складского ресурса.
- Также проверяются свободное место и наличие предыдущего юнита для апгрейда.
- Недоступные карточки затемняются, перечёркиваются и содержат точную причину блокировки.
- Ошибки, возвращённые сервером при найме, выводятся пользователю.
- API найма генерала принимает выбранный `catalog_id`; прежний вызов без него сохранён для совместимости.
