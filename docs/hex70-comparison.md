# Временная копия с уменьшенными гексами

Опубликована 16.09.2026: https://rhisseth.ru/interactive-map-hex70/.
Оригинал: https://rhisseth.ru/interactive-map/.

Сторона/радиус гекса уменьшены на 30%: 80 → 56 единиц SVG.
Полотно остаётся 3200×2200, фон Artistic V5 и оформление сохранены.
Число пересекающих полотно ячеек: 465 → 918. Площадь отдельной
ячейки составляет 49% исходной; уменьшение на 30% относится к линейному размеру.

Ссылка отсутствует в навигации сайта. Вход обязателен; листинг каталога
отключён, установлены `noindex, nofollow` и `Cache-Control: no-store`.
Знание адреса само по себе не заменяет авторизацию.

Копия предназначена для визуального сравнения. Редактирование отключено,
параметры исходных гексов не привязаны к новой геометрии: совпадающие Q/R
у более плотной сетки обозначают другие участки фона. Данные PostgreSQL
не изменяются, форма не отправляет PUT-запросы.

На VPS файлы копии находятся в `/opt/rhisseth/previews/interactive-map-hex70/`.
Отдельный nginx location обслуживает копию и проверяет сессию через внутренний
запрос к существующему `/api/me`. Исходные frontend/backend не изменены.
Потребовалась только перезагрузка конфигурации nginx, без рестарта приложения
и без перезагрузки сервера. Конфигурация перед изменением сохранена в
`/opt/rhisseth/backups/20260916-121216-nginx-before-hex70.conf`.

Сценарий публикации: `scripts/automation/Publish-Hex70PreviewVps.py`.
Запускается только через STU-AUTOMATION-01; отказывается перезаписывать
существующую тестовую директорию. Для удаления сравнения удалить только
помеченный блок nginx для `interactive-map-hex70`, проверить `nginx -t`,
перезагрузить конфигурацию и затем удалить отдельную директорию копии.
Не восстанавливать старый конфиг целиком поверх последующих изменений.
