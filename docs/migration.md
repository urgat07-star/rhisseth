# Источник и порядок переноса

Источник — рабочий каталог `Strat.elvizzz/interactive-map`, Final V2, а не
архивные delivery v1.1/v1.2. Перенесены интерфейс, CSS, финальный PNG,
актуальный `hex-initial-parameters.csv`, документы параметров и обзор данных.
Генераторы сохранены отдельно как справочные исходники. Архивные изображения,
дубли данных, delivery-пакеты, ключи, окружения и старые deployment-шаблоны
не являются частью работающего нового приложения.

1. Перед реальным переключением остановить редактирование старой карты.
2. Получить актуальный CSV и PNG с места эксплуатации разрешённым способом;
   локальный исходник не гарантирует наличие последних серверных правок.
3. Проверить CSV через `import_csv.py --check-only`, сохранить хеш и копию.
4. Создать пустую БД, выполнить миграции, импортировать одним transaction.
5. Сравнить число строк, координаты и все поля с CSV, проверить карту,
   редактирование и сохранение после перезапуска.
6. Сделать дамп, проверить восстановление на отдельной БД, затем переключать DNS.
7. До завершения приёмки держать старую версию доступной для отката.
   После начала записи в новой БД откат требует переноса новых изменений;
   простое возвращение старого CSV их потеряет.

Импорт запрещён в непустую таблицу, чтобы повторный запуск не затёр правки.
CSV остаётся транспортным форматом, но не используется веб-приложением.
База обновляет JSONB атомарно; параллельные изменения разных полей объединяются.
При изменении одного поля действует последняя запись — версия/409 ещё не внедрены.
