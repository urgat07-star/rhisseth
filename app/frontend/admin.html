Параметры грабежа

Награда рассчитывается из гекса: золото = богатство, еда = плодородие, ресурс = богатство, крестьяне = треть населения с округлением вниз (минимум 1). Здесь редактируются мораль и срок повторного грабежа; старые поля награды оставлены только для совместимости схемы.

Соединения речных гексов

Для каждой реки добавьте отдельную цепочку соседних пар от истока до дельты. Разные реки не соединятся без добавленной пары между ними. Проверяйте координаты: названия рек пока не хранятся. Связь даёт половинный расход логистики.

Компьютерное владение

Выберите в таблице 2–10 соседних гексов. Баронство: 2–3, княжество: 4–6, королевство: 7–10.
