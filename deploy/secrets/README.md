Создайте здесь `db_password.txt` с отдельным случайным паролем PostgreSQL.
Файл игнорируется Git. Не передавайте пароль в командной строке.
При запуске контейнера приложения UID 10001 должен иметь доступ на чтение
к файлу; используйте ограниченную группу/ACL. Проверьте доступ внутри контейнера
без вывода содержимого. Учётная запись БД в MVP является владельцем базы;
перед расширением доступа выделите отдельную роль приложения без superuser.
