# Rhisseth — интерактивная стратегическая карта

Отдельный проект на основе `Strat.elvizzz/interactive-map`, состояние Final V2
на 16.09.2026. Целевой GitHub: https://github.com/urgat07-star/rhisseth.git.
Исходный проект не изменён. Первая тестовая версия развёрнута на VPS
16.09.2026: `https://62.113.109.168/` (временный self-signed TLS).
Текущий адрес: https://rhisseth.ru/interactive-map/ (публичный HTTPS).

Все материалы, связанные с Rhisseth, должны храниться **только внутри папки
проекта `rhisseth.ru/`**: код, deployment, скрипты, документация, технические
и управленческие отчёты, журналы операций и локальные результаты проверок.
Отчёты размещайте в `reports/`, журналы — в
`reports/automation-logs/YYYY-MM-DD/`, вспомогательные скрипты — в `scripts/`,
локальные окружения и кэши — в `.local/`. Не создавайте материалы Rhisseth
в общих папках соседних проектов. На runner используйте отдельную папку
`/home/avalon/rhisseth.ru/` с той же структурой хранения.
Санитизированные сводные отчёты проверки от 18.09.2026 публикуются в Git
вместе с [описанием выпуска](docs/releases/0.0.2-changes-2026-09-18.md).
Прочие локальные отчёты, журналы и окружения исключены из Git;
секреты остаются в Passbolt и защищённом хранилище контроллера.

| Каталог | Назначение |
|---|---|
| `app/backend` | FastAPI, PostgreSQL, редактирование гексов |
| `app/frontend` | Унаследованные HTML/CSS/JS и художественная карта |
| `app/site` | Оформление входа и регистрации из архива хостинга |
| `data/migrations` | Версионированная схема PostgreSQL |
| `data/import` | Начальный CSV только для одноразового импорта |
| `deploy` | Compose, Dockerfile, HTTPS и настройки VPS |
| `docs` | Архитектура, перенос, исходные правила и обзор параметров |
| `archive/strat-tools` | Исходные генераторы для справки; зависят от старой структуры |
| `tests` | Проверки данных и API |
| `scripts/automation` | Проверки через runner и создание отчётов |
| `reports` | Технические и Word-отчёты, журналы операций (локально) |
| `.local` | Тестовые окружения и кэши (локально) |

Рабочее приложение читает и изменяет только PostgreSQL, без CSV fallback.
В PostgreSQL координаты имеют составной первичный ключ, а исходные поля
сохраняются в JSONB без потери русских названий и пустых значений.
Это промежуточная схема совместимости; игровые сущности и типизированные
характеристики можно вводить следующими миграциями.

Запуск и перенос: [deploy/README.md](deploy/README.md).
Первый тестовый VPS 1 CPU / 1 GB: [nginx + PostgreSQL 16 + systemd](deploy/native/README.md).
Предложения: [docs/architecture.md](docs/architecture.md).
Происхождение: [docs/migration.md](docs/migration.md).

Перерисовка OpenAI временно не подключена: прежний генератор использовал CSV.
Текущий PNG сохранён. Сайт использует PostgreSQL-аккаунты и серверные сессии:
после входа пользователь переходит на карту. `admin`/`moderator` редактируют,
`user` просматривает. Регистрация создаёт только `user`. Пароли из старой БД
сохраняются как bcrypt-хеши; исходные архивы и персональные данные не входят в Git.
Добавлена проверка ревизии гекса при сохранении из форм. История изменений
и несколько карт относятся к следующему этапу.

18.09.2026: [таблица гексов и начальные баронии](docs/hex-table-and-baronies.md).
Административный интерфейс: https://rhisseth.ru/admin/hexes (`admin`/`moderator`).
Географические названия меняет администрация; названия своих территорий —
владельцы. Начальный титул — барон; барония из 2–3 соседних гексов выдаётся
случайно или выбирается из доступных вариантов. Текущая карта — Artistic V6.

GitHub: Git-репозиторий находится только в этой папке. Сохраняйте существующую
историю удалённого репозитория; не используйте force push.
Секреты, дампы, старые доставки и журналы исходного проекта не копировались.
Локальный Git-репозиторий и remote `origin` уже созданы. 16.09.2026 Git
переведён на OpenSSL с проверкой TLS, выполнен fetch, main привязана к
существующему Initial commit. Первый коммит с приложением публикуется поверх
этой истории в `main` по поручению пользователя.

Панель пользователей: https://rhisseth.ru/admin/users (только администраторы). Поиск, редактирование логина/e-mail и смена группы; модераторы сохраняют редактирование карты.
