# Rhisseth — последовательность действий

## Запуск

Открыть PowerShell и выполнить:

```powershell
Set-Location C:\Avalon-repo\rhisseth.ru\tools
```

Главный файл: `rhisseth-sync.ps1`.
Отчёты: `C:\Avalon-repo\rhisseth.ru\reports\Git-sync\`.

Для интерактивного режима запустите файл без параметров:

```powershell
.\rhisseth-sync.ps1
```

В открывшемся меню выберите номер действия. Результат появится в том же окне. После завершения можно вернуться в меню и выполнить следующую операцию. Для выхода выберите пункт `0`.

## Перед началом работы

```powershell
.\rhisseth-sync.ps1 status -Branch main
```

Проверьте локальный репозиторий, GitHub и VDS. Нормальный результат: локальный commit совпадает с GitHub, `VdsStatus: Synchronized`, `VdsFilesChanged: False`.

Если GitHub новее:

```powershell
.\rhisseth-sync.ps1 pull-github -Branch main
```

## Изменение и публикация

1. Перейдите в `C:\Avalon-repo\rhisseth.ru`.
2. Внесите изменения и выполните тесты.
3. Проверьте `git status` и `git diff`.
4. Опубликуйте изменения:

```powershell
Set-Location C:\Avalon-repo\rhisseth.ru\tools
.\rhisseth-sync.ps1 push-github -Branch main
```

Введите обязательный комментарий коммита. Этот текст без замены станет темой commit и будет отдельно записан в отчёте `reports/Git-sync/`.

5. Проверьте GitHub:

```powershell
.\rhisseth-sync.ps1 status -Branch main
```

## Развёртывание на VDS

После успешной публикации в GitHub:

```powershell
.\rhisseth-sync.ps1 deploy-vds -Branch main
```

Перед загрузкой создаётся backup в `/var/backups/rhisseth/`. Скрипт запросит подтверждение `YES`. После развёртывания снова выполните `status` и проверьте тестовый сайт.

## Изменения, сделанные на VDS

Не запускайте сразу `deploy-vds`. Сначала импортируйте состояние:

```powershell
.\rhisseth-sync.ps1 pull-vds -Branch vds/import -Commit
Set-Location C:\Avalon-repo\rhisseth.ru
git diff main..vds/import
```

Пункт 5 также обязательно запрашивает комментарий: он записывается в созданный commit и отдельным полем в отчёт Git-sync.

После проверки объедините нужные изменения с `main`, затем выполните `push-github` и `deploy-vds`.

## Откат

Список backup на VDS:

```powershell
$cfg = Get-Content .\vds-credentials.json -Raw | ConvertFrom-Json
ssh -i $cfg.KeyPath "$($cfg.User)@$($cfg.Host)" "ls -lh /var/backups/rhisseth"
```

Откат:

```powershell
.\rhisseth-sync.ps1 rollback-vds -Backup rhisseth-YYYYMMDD-HHMMSS.tgz
```

Подтвердите операцию вводом `YES`, затем выполните `status`.

## Запрещено

- использовать `git push --force`;
- отключать backup через `-SkipBackup` в обычной работе;
- выполнять `deploy-vds`, если `VdsFilesChanged: True`, пока изменения VDS не импортированы;
- хранить `vds-credentials.json` и приватный SSH-ключ в GitHub.
